# kanri — Claude Code で作ったアプリの台帳とランチャー

自分の PC で動く、依存パッケージゼロのローカルダッシュボードです。
Claude Code で作ったアプリを一覧にし、**ワンクリックで起動・停止**でき、
**どこまで作ったか（ステータス・TODO・メモ）**を記録しておけます。

- 外部にデータを送りません。台帳は `data/apps.json` の 1 ファイルだけです。
- GitHub の情報は API ではなく手元の `git` コマンドから読むので、
  アクセストークンの発行もネットワーク接続も不要です。
- `127.0.0.1` だけで待ち受けるため、同じネットワークの他の PC からは接続できません。

## デスクトップに置く（macOS）

### 1. kanri を Mac に取り込む

まだ Mac に kanri のファイルが無い場合は、先に取り込みます。
**ターミナル.app** を開いて、次をそのまま貼り付けて実行してください。

```bash
cd ~
git clone -b claude/zealous-fermi-4748cv https://github.com/Yusei0003/kanri.git
```

ホームフォルダの下に `kanri` というフォルダができます。

> `git` が入っていない場合は「コマンドライン デベロッパ ツールをインストール」という
> ダイアログが出ます。「インストール」を押して、終わってからもう一度実行してください。

### 2. デスクトップにアイコンを作る

```bash
cd ~/kanri
sh scripts/install-mac.sh
```

デスクトップに **kanri** のアイコンができます。
以降は、そのアイコンをダブルクリックするだけでブラウザに kanri が開きます。

> `scripts/install-mac.sh: No such file or directory` と出る場合は、
> `cd ~/kanri` を実行し忘れています。`pwd` と打って、
> `/Users/あなたの名前/kanri` になっているか確かめてください。

### 3. 最新版に更新するとき

```bash
cd ~/kanri
git pull
sh scripts/install-mac.sh
```

### 使ううえでのメモ

- すでに起動していれば、二重に立ち上げずタブを開くだけです
- **終了**は画面右上の「終了」ボタン。kanri から起動したアプリもまとめて停止します
- Finder から起動すると PATH がほぼ空になるため、Homebrew・nvm・fnm・Volta・
  公式インストーラの標準的な場所から node を自動で探します。
  見つからないときは、その旨をダイアログで知らせます
- 置き場所を変えたいときは引数で指定できます: `sh scripts/install-mac.sh /Applications`
- kanri のフォルダを移動したら、`scripts/install-mac.sh` をもう一度実行してください
- PC を起動したら自動で立ち上げたい場合は、
  「システム設定 → 一般 → ログイン項目」にこのアイコンを追加してください

## ターミナルから動かす

Node.js 18 以上が入っていれば、インストール作業は不要です。

```bash
node server.js
```

`npm start` でも同じです。起動するとブラウザで <http://localhost:7788> が開きます。

- ポートを変えたいとき: `PORT=8080 node server.js`
- ブラウザを自動で開かせたくないとき: `KANRI_NO_OPEN=1 node server.js`
- 終了は `Ctrl + C`、または画面右上の「終了」ボタン。
  どちらでも、kanri から起動したアプリをまとめて停止してから終了します

## 使い方

### 1. アプリを登録する

一番手間がかからないのは **監視フォルダ**（トップバーの「監視フォルダ」）です。
Claude Code のプロジェクトを普段まとめて置いている親フォルダ
（例: `C:\Users\you\projects`）を登録しておくと、kanri が数分おきにその下を見にいき、
新しい git リポジトリを見つけたら **「構想」ステータスで自動登録**します。
名前・説明・起動コマンドは `package.json` や `README.md` から推測します。
以降は、新しいアプリを作ってもいちいち手動で登録する必要がありません。
自動登録されたカードには「自動検出」バッジが付き、手動編集しても消えません。

> 監視は kanri が起動している間だけ動きます。次に開いたときにもまとめて反映されるので、
> 常時起動していなくても実用上困りません。

一度きりでいいなら **「フォルダをスキャン」** で親フォルダを指定し、
見つかったものにチェックを入れて「選んだものを登録」で一括登録できます。

個別に登録したいときは **「＋ アプリを登録」** から。
ローカルフォルダのパスを入れて **「自動入力」** を押すと、
名前・説明・起動コマンド・GitHub URL を推測して埋めます
（すでに入力済みの項目は上書きしません）。必須項目は名前だけです。

| 項目 | 説明 |
| --- | --- |
| ローカルフォルダのパス | リポジトリのある場所。ここを作業ディレクトリとしてコマンドを実行します |
| 起動コマンド | 例: `npm run dev` / `python app.py` |
| ポート | 指定すると環境変数 `PORT` として渡し、`http://localhost:ポート` を「開く」対象にします |
| ステータス | 構想 / 開発中 / 試験運用 / 運用中 / 凍結 |
| タグ | カンマ区切り。検索の絞り込みに使います |

### 2. 起動する

カードの **「▶ 起動」** で子プロセスとして立ち上がります。

- **開く** — 設定した URL をブラウザで開く
- **フォルダ** — エクスプローラー / Finder でフォルダを開く
- **claude をコピー** — `cd "パス" && claude` をクリップボードへ。貼り付ければ続きの開発にすぐ入れます
- **詳細 → 起動ログ** — 標準出力・標準エラーを直近 400 行まで表示（自動更新あり）

「■ 停止」で、そのコマンドが生んだ子プロセスごと停止します。

### 3. 進捗を記録する

カードの **「詳細」** から、アプリごとに残せます。

- **TODO** — 次にやることのチェックリスト。カードに進捗バーが出ます
- **メモ** — 設計の意図、詰まった点、引き継ぎ事項。入力すると自動保存されます

一覧上部には最終コミットからの経過時間と未コミット件数が出るので、
「触りかけで止まっているもの」がひと目で分かります。

## 構成

```
server.js          HTTP サーバーと JSON API（依存なし）
scripts/launch.sh       起動用。node を探し、起動済みならブラウザを開くだけ
scripts/install-mac.sh  デスクトップに kanri.app を作る
scripts/make-icon.js    アイコンを生成（zlib だけで PNG を書き出す）
lib/store.js       台帳（data/apps.json）の読み書き
lib/runner.js      子プロセスの起動・停止・ログ保持
lib/git.js         git コマンドからブランチ・最終コミットを取得（30秒キャッシュ）
lib/scan.js        フォルダ走査と起動コマンドの推測
public/            画面（素の HTML / CSS / JavaScript）
data/apps.json     台帳。git 管理からは除外しています
```

### API

| メソッド | パス | 用途 |
| --- | --- | --- |
| GET | `/api/apps` | 一覧（起動状態と git 情報つき） |
| POST | `/api/apps` | 登録 |
| PATCH / DELETE | `/api/apps/:id` | 更新 / 削除 |
| POST | `/api/apps/:id/start` `/stop` | 起動 / 停止 |
| GET | `/api/apps/:id/logs` | 起動ログ |
| POST | `/api/apps/:id/open` `/reveal` | URL を開く / フォルダを開く |
| POST | `/api/scan` | フォルダ走査 |
| POST | `/api/import` | 走査結果の一括登録 |
| POST | `/api/probe` | フォルダから名前・起動コマンドなどを推測（登録フォームの自動入力用） |
| GET / PUT / PATCH | `/api/settings` | 設定。`scanRoots` を変更すると即座に一度スキャンする |
| GET | `/api/health` | 起動確認（ランチャーが使用） |
| POST | `/api/shutdown` | kanri 自身を終了 |

## 安全のための作り

kanri は登録された起動コマンドをそのまま実行できるため、次の制限をかけています。

- `127.0.0.1` だけで待ち受ける（同じネットワークの他の PC からは接続できない）
- `Host` ヘッダが `localhost` / `127.0.0.1` 以外のリクエストは拒否する（DNS リバインディング対策）
- 更新系リクエストは `Origin` の一致を必須にし、`content-type: application/json` 以外を拒否する
  （ブラウザで開いている別のサイトから API を叩かれるのを防ぐ）

そのうえで、**起動コマンドはシェル経由でそのまま実行されます**。
自分で内容を確認したコマンドだけを登録してください。

## 注意

- 台帳のバックアップは `data/apps.json` をコピーするだけです。PC を入れ替えるときはこのファイルを持っていけば復元できます。
- 起動ログは `data/server.log` に追記されます。うまく起動しないときはここを見てください。
